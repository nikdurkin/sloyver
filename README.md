# Слойвер Desktop

**Слойвер помогает выбрать, как напечатать деталь на FDM-принтере.** Если у вас уже есть 3D-модель и нужно решить, какой стороной положить деталь на стол, какой материал взять и сколько будет стоить печать, сравните варианты в Слойвере до нарезки.

## Когда пригодится Слойвер

- **Вы выбираете положение детали.** Загрузите модель в формате STEP, STL, OBJ или 3MF и сравните ориентации. Укажите, что важнее для этой детали — прочность, геометрия или баланс.
- **Деталь будет работать под нагрузкой.** Например, для настенного кронштейна отметьте место крепления к стене и задайте силу на свободном конце. Слойвер поможет предварительно оценить, где деталь испытывает наибольшие напряжения и где стоит попробовать локальное усиление.
- **Нужно оценить расход и цену.** Выберите принтер и материал, чтобы оценить расход филамента и стоимость печати. Для расчёта по собственным ценам укажите стоимость филамента за килограмм.

## Попробовать на примере

1. [Скачайте Sloyver.exe для Windows x64](https://github.com/nikdurkin/sloyver/releases/latest/download/Sloyver.exe) и откройте файл. Это переносная версия.
2. Нажмите **«Попробовать пример»** или **«Открыть модель»**. Задайте опоры и нагрузку, если они известны. Если нужна только подготовка к печати, пропустите проверку нагрузки.
3. Посмотрите рекомендации по ориентации, материалу и параметрам печати. Сохраните 3MF и откройте его как проект в Bambu Studio. Проверьте настройки и предпросмотр слоёв перед отправкой на принтер.

Оценка прочности зависит от заданных нагрузок и свойств материала. Если от прочности детали зависит безопасность, подтвердите её испытанием напечатанного образца.

## Сборка из исходников на Windows x64

Понадобятся Git и Node.js **22.12.0 или новее** с npm. При первой сборке нужен интернет для загрузки зависимостей, Electron и инструментов упаковки. Команды ниже выполняются в PowerShell.

### 1. Получите исходники

```powershell
git clone https://github.com/nikdurkin/sloyver.git
cd sloyver
```

### 2. Подготовьте модуль для импорта STEP

Загрузите WebAssembly-модуль Open CASCADE из закреплённой версии проекта occt-import-js. Контрольная сумма соответствует модулю из дистрибутива Слойвер 1.8.0.

```powershell
$wasm = 'renderer/vendor/occt/occt-import-js.wasm'
$url = 'https://raw.githubusercontent.com/kovacsv/occt-import-js/41e470890ae0f9dc69ac50ffd5fc73e03576f4eb/dist/occt-import-js.wasm'
Invoke-WebRequest -UseBasicParsing -Uri $url -OutFile "$wasm.download" -ErrorAction Stop
$expected = '33391fc9d94ea5c869a6718488bf0a9a464222bac9bdc764dfe1690cef281952'
if ((Get-FileHash -Algorithm SHA256 -LiteralPath "$wasm.download").Hash -ne $expected) {
    throw 'Контрольная сумма модуля STEP не совпала. Повторите загрузку.'
}
Move-Item -Force -LiteralPath "$wasm.download" -Destination $wasm
```

### 3. Установите зависимости и запустите тесты

```powershell
npm ci
npm test
```

Для запуска приложения в режиме разработки выполните `npm start`.

### 4. Соберите приложение

| Вариант для Windows x64 | Команда | Результат для версии 1.8.0 |
| --- | --- | --- |
| Переносная версия | `npm run build:win` | `release/Sloyver-Desktop-1.8.0-Windows-x64.exe` |
| Установщик NSIS | `npm run build:installer` | `release/Sloyver-Setup-1.8.0-Windows-x64.exe` |
