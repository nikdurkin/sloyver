SLOYVER · Desktop 1.8.0

Windows x64 · 28 October 2026

A local assistant for FDM print orientation, material selection, load analysis, starting print settings and order estimates. The application works offline; online exchange-rate refresh is optional. It is not an official Bambu Lab product.

Getting started

  1. Run Sloyver.exe. This single file contains the application. No installation is required.
  2. Model. Select “Open a model” or “Try a sample”. Check the shape and dimensions. Optionally describe its use and choose a priority.
  3. Load. Select where the part is held, then where it is pushed, pulled or twisted. Enter the load amount and check the arrow direction. If the load is unknown, use “Skip the load check for now”.
  4. Result. Review the assessment and recommendations. Choose your printer and material under “Printer and material”. The app suggests a material; your manual choice is preserved.
  5. Select “Save print file · 3MF”. Open it in your slicer, review the settings and layer preview, slice it and send the result to your printer.

Need help? The Help button explains the basic terms and illustrates supports and loads. Detailed settings, the mesh and stress values are available in expandable sections. RU / EN switches the interface language.

About load checking. This is a preliminary assessment based on your conditions and material properties. If the check is skipped, the interface says so. Coarse geometry and incomplete material data do not become a confirmed strength verdict.

A .sloy project retains the editable model, loads, comments and results. A 3MF file is for print preparation; settings and reinforcement compatibility depend on the slicer.

New in 1.8.0

One task panel, three large steps, larger headings and primary buttons, a clean first-run screen, beginner explanations, a simpler check form, a concise assessment and clear post-export instructions. Existing engineering controls and projects remain available.

Technical details and version history

New name in 1.7.2

The application is now called Sloyver (Слойвер in Russian). The interface, menus, reports and exported 3MF files use the new name. Run Sloyver.exe. Existing .sloy projects, language, history and settings keep using the same data profile.

Fixes in 1.7.1

Reinforcement now changes only infill to 100%, with no local wall override. Legacy per-region wall counts are discarded. Modifier resources have type other and native modifier_part roles under one printable part. They appear as child entries in the object tree. Open the 3MF as a project to retain them.

New regions enclose connected loaded areas with a margin; nearby regions merge. Enlarge one or all enabled regions by 1.5 in the region editor, then apply and recalculate.

Analysis limits increased to 100,000 elements, 160,000 nodes and 4,000,000 domain cells. Automatic meshing can coarsen to continue with small selected holes. Approximate hole/support/load patches are clearly marked. Force and moment are preserved, but local stress near them is unreliable and cannot confirm load capacity. Invalid geometry, unconstrained motions and solver failure still stop analysis.

Start and language

Close the previous version, extract the ZIP and run Sloyver.exe. Existing local projects remain in %APPDATA%\SloyDesktop. Save important projects with Ctrl+S before updating. Use RU / EN in the header to switch language. The choice persists on this computer and applies to the main interface and desktop menus. User names, file names and comments are preserved. Technical reports and embedded 3MF comments may retain Russian text.

Prepare a print

  1. Load STEP/STP, STL, OBJ or 3MF. Select one body if necessary. Check STL/OBJ units. Pick strength, geometry or balance as the goal.
  2. Under Load, choose a support on a face or circle, then apply forces or moments elsewhere. Directions use the original model axes. You can also choose a working direction for quick orientation advice. Hover over a circular rim or centre to select it; use a three-point circle if needed.
  3. Under Print, select a printer and review the suggested material. Choosing your own material preserves that choice. Run Find orientations and review the model, warnings, settings and cost.

Place face on bed fixes the desired contact plane. Replacing a model, body or units clears geometry-dependent supports and loads. The bed becomes semitransparent below the horizon and never intercepts model selection.

Printers and custom materials

The catalogue contains 14 printer models and 56 nozzle combinations from Bambu Studio 02.08.02.61: A1, A1 mini, A2L, P1P, P1S, P2S, X1, X1 Carbon, X1E, X2D, H2C, H2D, H2D Pro and H2S. This describes profiles in that release, not retail availability. Stock presets use their recorded dimensions and nozzle combinations.

For General — custom printer, enter build dimensions and a 0.1–2 mm nozzle. For General — custom material, enter name, family, in-plane / through-layer Young’s moduli, density, temperatures and optional tensile strengths and price. Initial properties are editable assumptions. Unknown strength and impact data remain unknown. Strength entries require a source and test conditions.

Check under load

The material selector is available in the analysis setup. Changing material updates elastic and strength data, invalidates old results and clears previous material calibration. Manual infill and accepted reinforcement regions are retained. You can analyse a solid part or an approximate printed shell and homogenised infill.

The result starts with a plain-language assessment and a possible weak region. This is not a predicted crack path. Known Bambu TDS tensile strengths provide a partial numeric estimate; missing compression and shear properties are listed rather than invented. Sparse infill uses an uncalibrated equivalent-solid strain screening, not calculated filament-level stresses.

A confirmed allowable-load verdict requires all six strength properties with sources, a solid calculation medium, valid equilibrium and geometry, small strains and mesh-refinement checks. TDS mean values do not guarantee the capacity of your printed part. Fracture, plasticity, impact, contact and buckling are not simulated.

For low-margin or overloaded sparse regions, try Reinforce regions and recalculate. The app proposes up to three boxes with 100% infill. Up to eight regions can be edited, enabled or removed. Regions affect material already inside the CAD part; holes are not filled. Inspect the new result: reinforcement may not resolve the issue. Refine analysis to compare mesh sensitivity.

Export a print project

Use Print project · 3MF from orientation or analysis results. Review printer and temperatures, then save. The file transfers orientation in millimetres, material, layer height, walls, infill, solid top/bottom layers, supports, brim and main speeds. Accepted reinforcement boxes become native modifier_part volumes with 100% infill. Parts and modifiers share the same rigid transform.

Open in Bambu Studio, inspect settings and modifiers, then slice. Native compatible presets are referenced where available; no G-code is included. General exports a custom machine definition with empty start/end G-code. Complete machine, cooling, flow and compatibility settings in the slicer. Wall and solid-layer thicknesses round up to complete lines/layers. The selected FEM recipe is used for a current analysis. Save a .sloy project as well to retain the editable loads and complete result.

Reading and round-trip preservation were checked with official Bambu Studio 02.08.02.61 on Linux. Actual test slicing confirmed local dense-infill toolpaths. OrcaSlicer is an intended target but was not run separately. Cloud-browser 3MF download was not confirmed; the desktop application uses native file saving.

Prices and currency

Configure the order estimate to choose official Bambu Lab US / EU prices or your purchase price in RUB/kg. The official snapshot is dated 2026-10-28, with 17 of 18 materials verified; PETG Basic requires manual pricing. Prices identify a selected variant and pack mass, excluding bulk, membership and coupon discounts, shipping, customs and bank fees.

USD / EUR convert to RUB using CBR rates. Desktop can refresh rates online; both rates are editable. Manual rates persist and are not replaced automatically. Your purchase price takes priority. Support material and waste are estimated before slicing. Imported total slicer mass takes priority without adding support mass twice.

Projects and validation

Ctrl+S saves geometry, comments, orientation, load setup, custom properties, currency, pricing, analysis and reinforcement. Project format 8 reads versions 1–8. Older app versions cannot open new projects. Use Ctrl+O for a model and Ctrl+Shift+O for a project; Ctrl+P exports a PDF report.

The EXE is unsigned and was cross-built on Linux. It was not launched on native Windows in this environment. Automated module checks, browser interface checks and Linux Bambu Studio import / slicing checks are recorded in validation.json.
